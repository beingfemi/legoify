# Legoify — superseded

This project has been split into two independent projects.

| | Repo | Live |
|---|---|---|
| **Character** — brick figure in your photo's colours | [legoify-character](https://github.com/beingfemi/legoify-character) | https://legoify-character.vercel.app |
| **Likeness** — depth model rebuilds the photo's real 3D shape | [legoify-likeness](https://github.com/beingfemi/legoify-likeness) | https://legoify-likeness.vercel.app |

This repo is archived and no longer developed. Its full history lives on in
both successors.
